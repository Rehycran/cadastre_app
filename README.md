Petite application avec interface permettant à partir d'une adresse de générer un fichier DXF organisé par calques.  
  
Sur une emprise carrée autour de l'adresse, le DXF contient le parcellaire, les countours du bâti, les points altimétriques au pas défini par l'utilisateur.  
Cet outil utilise les services WFS et Altimétrie de la Géoplateforme (IGN), les sources utilisées sont donc RGE Alti, BDTOPO v3, BDPARCELLAIRE et Geocodage.

Petite aplpication avec interface permettant à partir d'une adresse de générer un fichier DXF organisé par calques.
Sur une emprise carrée autour de l'adresse, le DXf contient le parcellaire, les countours du bâti, les points altimétrique au pas déifni par l'utilisateur.
Cet outil utilise les services WFS et Altimetrie de la Géoplateforme (IGN), les sources utilisées sont donc RGE Alti, BDTOPO v3, BDPARCELLAIRE et Geocodage.
